BPMN (Business Process Model and Notation) membantu memetakan urutan kerja; REA (Resources, Events, Agents atau sumber daya, kejadian, dan pelaku) membantu memetakan hubungan datanya. Pemisahan tugas atau SoD menjadi bagian dari pengendaliannya.
