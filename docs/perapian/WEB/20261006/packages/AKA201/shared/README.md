# AKA201 shared: daftar file

| File | Isi | Dipakai untuk |
|---|---|---|
| `source_inventory.md` | Inventaris sumber dan status verifikasinya | Semua TM |
| `benang_merah_TM01-07.md` | Alur delapan langkah TM01–TM07, satu contoh terpadu, 10 pertanyaan fondasi | Halaman ringkasan pra-UTS |
| `panduan_menjawab_kasus.md` | Rubrik AOL, lima langkah menjawab kasus, contoh satu soal dengan tiga level jawaban, daftar periksa | Halaman panduan belajar |
| `latihan_skenario_UTS.md` | Tujuh skenario lintas TM (enam dengan pembahasan beranotasi level rubrik, satu latihan mandiri) | Halaman latihan pra-UTS |
| `panduan_tampilan_dan_bahasa.md` | Aturan lapisan bacaan, kepadatan, navigasi, latihan, bahasa antarmuka, dan pengecekan visual pilot | Agen coding (wajib dibaca sebelum implementasi) |
| `latihan_penyelesaian_masalah_SCPMK2.md` | Format jawaban, contoh pernyataan penggunaan AI, tiga kasus dengan kerangka jawaban, daftar periksa peer assessment | Halaman persiapan tugas Penyelesaian Masalah |

Catatan implementasi: pembahasan skenario dan contoh jawaban sebaiknya dirender tersembunyi di balik tombol, sama seperti "Uji pemahaman" di tiap TM, agar mahasiswa menjawab sendiri lebih dulu.
