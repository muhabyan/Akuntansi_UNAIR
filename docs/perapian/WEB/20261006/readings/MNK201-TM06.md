blocks[5] h2: Pilar I: Formula & Cara Menghitung 5 Kriteria Capital Budgeting

blocks[6] formula: \text{1. Net Present Value (NPV)}: \quad NPV = \sum_{t=0}^N \frac{CF_t}{(1 + WACC)^t} = \left( \sum_{t=1}^N \frac{CF_t}{(1 + WACC)^t} \right) - |CF_0|
\text{2. Internal Rate of Return (IRR)}: \quad \sum_{t=0}^N \frac{CF_t}{(1 + IRR)^t} = 0 \implies |CF_0| = \sum_{t=1}^N \frac{CF_t}{(1 + IRR)^t}
\text{3. Modified IRR (MIRR)}: \quad PV_{\text{Costs}} = \frac{TV_{\text{Inflows}}}{(1 + MIRR)^N} \implies MIRR = \sqrt[N]{\frac{\sum_{t=1}^N CF_t (1 + WACC)^{N - t}}{|CF_0|}} - 1
\text{4. Payback Period (PP)}: \quad PP = A + \frac{B}{C} \quad (A = \text{tahun terakhir kas kumulatif negatif}, B = \text{sisa modal belum balik}, C = \text{kas masuk tahun berjalan})
\text{5. Discounted Payback (DPP)}: \quad DPP = A + \frac{B_{\text{terdiskon}}}{PV(C)}

blocks[14].blocks[0] ul: **Jawaban Bagian b (Jika Proyek Bersifat Independent)**:
- **Keputusan: TERIMA KEDUA PROYEK (Project X dan Project Y keduanya diterima!)**.
- *Alasan*: Karena kedua proyek bersifat independen, keduanya tidak saling menghalangi. Kriteria penerimaan adalah $NPV > 0$ dan $IRR > WACC$. Karena Project X ($NPV = +966,01; IRR = 18,03\% > 12\%$) dan Project Y ($NPV = +630,72; IRR = 14,96\% > 12\%$) keduanya menghasilkan nilai tambah positif, maka kedua proyek wajib dijalankan bersama-sama. | **Jawaban Bagian c (Jika Proyek Bersifat Mutually Exclusive pada WACC = 12%)**:
- **Keputusan: PILIH PROJECT X!**
- *Alasan*: Proyek saling meniadakan hanya mengizinkan kita memilih satu proyek terbaik. Project X memiliki $NPV$ lebih tinggi ($+966,01 > +630,72$) dan juga $IRR$ lebih tinggi ($18,03\% > 14,96\%$). Pada tingkat bunga 12%, tidak terjadi konflik antara NPV dan IRR. | **Jawaban Bagian d (Analisis Konflik Jika WACC = 5%)**:
- Mari kita hitung ulang NPV kedua proyek pada suku bunga diskonto rendah **WACC = 5%**:
  $$NPV_X (5\%) = -10.000 + \frac{6.500}{1,05} + \frac{3.000}{(1,05)^2} + \frac{3.000}{(1,05)^3} + \frac{1.000}{(1,05)^4} = \mathbf{+2.325,78}$$
  $$NPV_Y (5\%) = -10.000 + 3.500 \times PVIFA_{5\%, 4} = -10.000 + (3.500 \times 3,54595) = \mathbf{+2.410,83}$$
- **Evaluasi Hasil**: Lihat apa yang terjadi!
  - Berdasarkan kriteria **NPV**: Project Y menang ($NPV_Y = 2.410,83 > NPV_X = 2.325,78$)!
  - Berdasarkan kriteria **IRR**: Project X tetap menang ($IRR_X = 18,03\% > IRR_Y = 14,96\%$)!
- **Kesimpulan Bagian d: YA, TERJADI KONFLIK ANTARA NPV DAN IRR PADA WACC = 5%!**
  - Titik persimpangan (*Crossover Rate*) terjadi pada tingkat diskonto **6,22%**.
  - Jika WACC < 6,22% (seperti pada 5%), Project Y memiliki NPV lebih tinggi.
  - Jika WACC > 6,22% (seperti pada 12%), Project X memiliki NPV lebih tinggi.
  - *Keputusan yang benar saat konflik*: **Pilih Project Y** karena NPV-nya lebih tinggi! | **Jawaban Bagian e (Mengapa Dapat Terjadi Konflik Antara NPV dan IRR?)**:
Ada dua penyebab mendasar mengapa NPV dan IRR bisa berselisih paham saat memeringkat proyek mutually exclusive:
1. **Perbedaan Pola Waktu Arus Kas (*Timing Differences*)**:
   - Project X adalah proyek "cepat panen" yang menerima kas sangat besar di awal (Tahun 1 = 6.500).
   - Project Y adalah proyek dengan kas masuk yang bertahan lebih lama dan merata (3.500 tiap tahun hingga tahun ke-4), dengan total kas masuk tanpa diskonto lebih besar (14.000 vs 13.500).
   - Saat suku bunga WACC tinggi (12%), arus kas tahun ke-3 dan 4 milik Project Y tergerus habis oleh diskonto yang berat sehingga Project X menang.
   - Namun saat suku bunga WACC rendah (5%), nilai waktu uang tidak terlalu "menghukum" kas di masa depan, sehingga total uang Project Y yang lebih besar akhirnya mengalahkan Project X!
2. **Perbedaan Asumsi Reinvestasi (*Reinvestment Rate Assumption*)**:
   - **Metode IRR mengasumsikan kas masuk direinvestasikan pada tingkat bunga IRR proyek itu sendiri** (18,03% untuk X dan 14,96% untuk Y). Ini sangat tidak realistis karena sulit bagi perusahaan menemukan proyek baru di pasar yang terus-menerus bisa menghasilkan untung setinggi 18%.
   - **Metode NPV mengasumsikan kas masuk direinvestasikan pada biaya modal (WACC)**, yaitu tingkat suku bunga pasar riil yang wajar (12% atau 5%). Asumsi NPV jauh lebih realistis!
   - Karena itulah, para profesor keuangan dan penguji UTS FEB UNAIR sepakat: **NPV adalah Raja Penganggaran Modal yang tidak pernah salah!**
