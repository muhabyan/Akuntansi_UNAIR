# EKT109 TM14

Hubungan konsep, penerapan, dan batas

Diminishing returns bukan penurunan level output saat modal naik.

Dengan tenaga kerja dan teknologi tetap, tambahan modal masih meningkatkan output, tetapi tambahan output per unit modal makin kecil. Catch-up bergantung pada kondisi teknologi, institusi dan investasi, sehingga negara berpendapatan rendah tidak otomatis tumbuh cepat. Perubahan teknologi dapat menggeser fungsi produksi.

Rujukan audit: Mankiw, Principles of Economics, Ch.25, bagian 25-3b, hal.513-514 PDF 550-551
