# EKT109 TM9

Hubungan konsep, penerapan, dan batas

Break-even rumah tangga berbeda dari keseimbangan output seluruh ekonomi.

Pada C = a + bY, titik C = Y berarti tabungan nol. Itu belum menunjukkan keseimbangan makro karena investasi, pemerintah atau sektor luar negeri dapat menambah pengeluaran. MPC = perubahan C / perubahan Y; MPS = 1 - MPC pada identitas disposable income yang sama. Nyatakan pajak jika pendapatan bruto dipakai.

Rujukan audit: Samuelson dan Nordhaus, Economics, Ch.21, fungsi konsumsi dan tabungan; slide lokal Closed Economy
