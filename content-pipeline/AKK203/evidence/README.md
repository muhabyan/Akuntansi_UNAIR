# Bukti verifikasi ASP

Delapan PNG merupakan contoh grafik kuantitatif TM9 dan TM14 pada kedua ukuran dan tema. Keseluruhan 160 PNG tersimpan lokal di qa-akk203-uas.local dan dapat dibuat ulang dengan skrip browser. visual-review.json mencatat hash seluruh PNG dan peninjauan 56 lembar kontak; browser-report.json mencatat 28 keadaan aplikasi. logs memuat keluaran pemeriksaan terakhir. Berkas PDF sumber tidak disalin ke Git.
